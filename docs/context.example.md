# Exemplo de `.devdoctor/context.md`

Copie para a raiz do seu projeto como `.devdoctor/context.md` e ajuste.

```markdown
# Contexto do projeto (DevDoctor)

- Gerenciador de pacotes: pnpm
- Node.js: 20 LTS
- Framework: React + Vite
- Testes: Vitest

Observações:
- Preferir explicacoes em português.
- Não sugerir downgrade de dependências sem avisar breaking changes.
```

O DevDoctor trunca o arquivo para limitar tokens enviados à IA.
