# Contribuindo

Obrigado pelo interesse em melhorar o DevDoctor CLI.

## Desenvolvimento

```bash
git clone https://github.com/warleymendeslopes/DevDoctor.git
cd DevDoctor
npm install
npm test
npm link   # opcional: usar `devdoctor` globalmente a partir deste clone
```

## Pull requests

- Descreva o problema ou a feature.
- Rode `npm test` antes de enviar.
- Atualize [estrutura.md](./estrutura.md) se mudar arquivos estruturais.

## Código

- Node.js 18+, ES modules (`"type": "module"`).
- Preferir mudanças pequenas e testáveis.
